# Sound Pad - 音声ファイルランチャー

RustとTauriで作成された音声ファイルランチャーアプリケーションです。SEやBGMの確認・整理に最適です。

## 機能

### 1. 音声ファイルの閲覧と再生
- フォルダを選択すると、対応する音声ファイル（MP3、WAV、OGG、FLAC、M4A、AAC）を自動的に読み込みます
- グリッド表示で見やすいレイアウト
- ワンクリックで音声を再生
- 別の音声をクリックすると、前の音声を自動停止して新しい音声を再生
- 下部プレイヤーからシーク、一時停止、停止、マスターボリューム調整が可能
- マスターボリュームは次回起動時も保持

### 2. Studio Deck UI
- 一覧、ライブラリナビゲーション、選択中ファイルの詳細を同時に確認できる3ペイン構成
- 各行の再生ボタンとファイル名コピーボタンを隣接配置
- 左パネルから現在フォルダ、サブフォルダ、保存ビュー、タグ別フィルターへアクセス
- タグごとに一貫した識別色を表示
- Light / Darkテーマを切り替え可能（選択したテーマを保持）
- リスト表示を既定とし、カード表示にも切り替え可能

### 3. フォルダ履歴とブックマーク
- **履歴機能**: 過去に開いたフォルダを自動的に記録（最大10件）
- **ブックマーク機能**: よく使うフォルダをブックマークに登録
- ワンクリックで履歴やブックマークからフォルダを開く
- 保存フォルダを右クリックして案件が分かる別称を設定
- 保存フォルダをルートとして、現在位置と下層フォルダをインデント表示
- ブックマークは削除ボタンで簡単に管理可能
- LocalStorageを使用してデータを永続化
- 保存フォルダやお気に入りの参照切れを検出し、指定フォルダ内の再帰検索でパスを一括修復
- 見つからない参照は別のフォルダで再検索するか、お気に入り・セットリストから選択削除

### 4. BGMプレイリスト
- 右パネルで複数のプレイリストを作成・切り替え
- 選択中の音声を追加し、重複を防止
- プレイリスト内から再生、ファイル名コピー、順序変更、削除が可能
- プレイリストと曲順はアプリデータ内の `playlists.json` に保存
- 選択中セットリストをPremiere Pro UXP受け渡し用JSONとして書き出し
- 右下の「次の曲候補」に、選択中の曲とムード・音響特徴が近い曲をランキング表示
- 現在フォルダ／お気に入りを候補範囲に選び、BPM許容差とハーフ／ダブルテンポ許可を指定可能
- 初回分析時に約20MBのONNXモデルを取得し、分析結果はファイル更新日時とともにキャッシュ

### 5. Premiere Pro UXP連携用JSON
- 複数タグをAND条件で絞り込み、該当するお気に入りをJSON書き出し
- お気に入りJSONとセットリストJSONを`format`フィールドで判別
- JSON形式の詳細は`docs/UXP_JSON_FORMAT.md`を参照

### 6. ファイル名の編集
- 各ファイル名を個別に編集可能（クリックして直接入力）
- 複数のファイルを選択して、一括で接頭辞・接尾辞を追加

### 7. ファイルの選択とコピー
- チェックボックスで複数のファイルを選択
- 選択したファイルを指定フォルダにコピー
- コピー前にファイル名の編集が可能
- **コピー完了モーダル**: コピー完了時にモーダルダイアログを表示
  - OKボタンでモーダルを閉じる
  - 「コピー先を開く」ボタンでコピー先フォルダを直接開く

## 使い方

### 開発環境での実行

```bash
npm run tauri dev
```

### プロダクションビルド

```bash
npm run tauri build
```

ビルド後、`src-tauri/target/release/`にインストーラーまたは実行ファイルが生成されます。

### Premiere Pro UXPパネル

`premiere-uxp/`には、書き出したお気に入り・セットリストJSONをPremiere Pro上で利用するUXPパネルがあります。開発時の読み込み方と操作方法は[`premiere-uxp/README.md`](premiere-uxp/README.md)を参照してください。

## 基本的な操作

1. **フォルダを選択**: 画面上部の「📁 フォルダを選択」ボタンをクリックして、音声ファイルが含まれるフォルダを選択

2. **ブックマークに追加**: フォルダを開いた後、「⭐ ブックマークに追加」ボタンでブックマークに登録

3. **履歴・ブックマークから開く**: 画面上部の履歴またはブックマークエリアから、過去に開いたフォルダやお気に入りのフォルダをクリックして素早く開く

4. **音声を再生**: 各ファイルの「▶ 再生」ボタンをクリックして音声を再生

5. **ファイル名を編集**: ファイル名をクリックして直接編集可能。Enterキーで確定

6. **複数ファイルの一括編集**:
   - チェックボックスで複数のファイルを選択
   - 「✏️ 選択項目の名前を編集」ボタンをクリック
   - 接頭辞と接尾辞を入力

7. **ファイルをコピー**:
   - チェックボックスで必要なファイルを選択
   - 「📋 選択項目をコピー」ボタンをクリック
   - コピー先のフォルダを選択
   - モーダルダイアログで「コピー先を開く」を選択すると、コピー先をアプリで開く

## 技術スタック

- **フロントエンド**: Vanilla JavaScript, HTML, CSS
- **バックエンド**: Rust
- **フレームワーク**: Tauri 2.x
- **音声再生**: rodio
- **ファイル操作**: std::fs, walkdir
- **データ永続化**: LocalStorage API

## 対応音声フォーマット

- MP3
- WAV
- OGG
- FLAC
- M4A
- AAC
